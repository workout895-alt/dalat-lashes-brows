# Brow & Lash Studio Da Lat — Multilingual Landing Page (@browsaigon)

Премиальный мультиязычный Landing Page (Single Page Application) мастера по ресницам и бровям в Далате (Вьетнам).

---

## 🌟 Возможности и структура проекта

1. **Мультиязычность без перезагрузки (EN | RU | VI):**
   - **EN (English):** Для иностранных туристов, digital nomads и экспатов в Далате.
   - **RU (Русский):** Для русскоязычных туристов, зимовщиков и экспатов.
   - **VI (Tiếng Việt):** Для местных жительниц Далата и гостей из других городов Вьетнама.
   - Автоматическое определение языка браузера и сохранение выбора в `localStorage`.
   - Динамическое обновление SEO Meta-тегов (`title`, `description`, `keywords`, `og:title`, `og:description`) при переключении языка.

2. **Local SEO оптимизация для рынка Вьетнама (Далат / Lâm Đồng):**
   - Структурированные микроданные **Schema.org (LocalBusiness / BeautySalon)** с геолокацией Далата (`11.9404, 108.4583`), часами работы и языковыми атрибутами.
   - Семантические теги `H1`, `H2`, `H3` с точечным вхождением целевых ключевых фраз под каждый язык.
   - Индексируемые `alt` атрибуты у каждого фото в галерее работ.
   - Блок Local SEO ключевых запросов в подвале страницы.

3. **Связь и конверсионные воронки (Мультиссылочный блок):**
   - **Telegram:** Прямой диалог с мастером Юлией (`@Yuliya_zateyka`).
   - **Instagram Direct:** Профиль `@browsaigon` (`https://www.instagram.com/browsaigon?exln=ZzJrdm`).
   - **Zalo:** Самый популярный мессенджер во Вьетнаме для местных клиентов.
   - **WhatsApp:** Удобный канал для англоязычных экспатов и путешественников.
   - Интерактивное модальное окно выбора мессенджера при клике на любую кнопку «Записаться / Book» с автоподстановкой выбранной услуги.

4. **Интерактивная карта Google Maps:**
   - Интегрированный фрейм карты Далата с координатами и быстрой кнопкой проложить маршрут.

5. **Мобильная адаптивность и UX:**
   - Мобильное всплывающее меню (Drawer).
   - Закрепленная нижняя плашка записи (Sticky Bottom Bar) для мобильных телефонов.
   - Микроанимации и чистая типографика (Cormorant Garamond + Plus Jakarta Sans).

## 📁 Структура файлов

- `index.html` — Основная разметка HTML5, мета-теги, Tailwind CSS конфигурация, Schema.org JSON-LD и компоненты.
- `style.css` — Дополнительные анимации, кастомный скроллбар и стилизация активных элементов.
- `script.js` — Движок мультиязычности (i18n), интерактивные функции модального окна и обработчики событий.
- `README.md` — Документация и инструкция по запуску и размещению.

## 🚀 Как запустить проект локально

Просто откройте файл `index.html` в любом браузере (Chrome, Edge, Safari, Firefox) двойным щелчком, либо запустите любой локальный статический сервер:

```bash
# Вариант 1 (Node.js npx):
npx serve .

# Вариант 2 (Python 3):
python -m http.server 8000
```
После этого сайт доступен по адресу `http://localhost:8000`.
